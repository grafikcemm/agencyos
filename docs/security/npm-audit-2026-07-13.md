## Gerçek risk değerlendirmesi

Zafiyet, PostCSS'in stringify çıktısına **saldırgan kontrollü CSS** girdiğinde
`</style>` kaçışsız kalması. Bu repo'da CSS girdileri yalnız kendi kaynak
dosyalarımız (tailwind + statik css) — kullanıcı/lead verisi CSS pipeline'ına
girmiyor. Sömürü yolu: YOK (bilinen). Risk: düşük; yine de takip edilir.
